Privacy Policy

Last updated: September 22, 2026

Jarvis Assistant ("Jarvis") is a personal tool operated by its owner for their own Google account. It has no other users.

What data Jarvis accesses

With the account owner's permission, Jarvis uses Google APIs to read, draft and send Gmail messages and to read and create Google Calendar events for that same account.

How the data is used

Data is used only to carry out requests the account owner makes to Jarvis (for example, "read my latest emails" or "what's on my calendar tomorrow"). It is not sold, shared, or used for advertising.

Where the data is stored

Jarvis runs on a self-hosted server controlled by the account owner. Google data is processed on request and is not kept in a separate database, except for execution logs on that server.

Google API Services User Data Policy

Jarvis's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
